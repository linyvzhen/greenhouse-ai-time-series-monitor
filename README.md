# 温室环境监测与AI时序预测可视化系统
> 面向黄瓜温室场景的数智化数据分析平台，完成全链路数据采集、清洗、时序建模、可视化预警，辅助种植环境研判与决策。

## 项目背景
黄瓜温室种植过程中，温湿度、光照、CO₂等环境指标直接影响作物生长。本项目搭建一套从数据采集到分析展示的完整平台，通过时序预测模型识别环境趋势，并结合AI智能问答辅助种植决策。

## 技术栈
- **数据库**：SQL Server
- **数据处理**：Python（Pandas / NumPy）
- **可视化**：Matplotlib / ECharts
- **前端页面**：HTML / CSS / JavaScript
- **AI能力**：时序预测模型 + 智能问答接口

## 核心功能
### 1. 数据存储与管理
- 设计温湿度、光照强度、CO₂浓度等多维度环境监测数据表
- 使用SQL编写数据筛选、关联聚合、异常值过滤查询
- 累计存储 **12万+条** 温室时序监测数据

### 2. 数据清洗与特征工程
- 使用Pandas对原始传感器数据进行降噪处理
- 处理缺失值、异常值，完成数据标准化
- 提取时段特征、周期特征，为模型训练做准备

### 3. AI时序预测
- 基于历史环境数据搭建时序预测模型
- 对未来温湿度变化趋势进行预测
- 预测误差控制在 **7%以内**，可提前识别环境风险

### 4. 可视化看板
- Web页面展示实时环境指标
- 历史数据走势图表化呈现
- 异常数据高亮预警

### 5. AI智能问答
- 集成大模型接口，支持黄瓜种植、温室管理相关问题咨询
- 结合实时环境数据给出针对性建议
